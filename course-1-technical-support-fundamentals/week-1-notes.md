### Digital Logic 

- Computer Language
  Binary System: the communication language that computers use, can also be known as the base-2 neural system, only talks in 1's and 0's
  We group binary into 8 numbers or BITS
  BIT is a binary digit
  A group of 8 BITS is known as a BYTE
  EACH BYTE can store one character, there are 256 possible values thanks to the base-2 system
  
-Character Encoding
  assigning binary values to character, so we as humans can read them 
  think of it as a dictionary 
  ASCII this is what we used to decipher HELLO, it represents the English alphabet, digits and punctuation marks 
  UTF-8 allows us to store more than one character in a BYTE emoji madness 
  RGB Model, eight combination of zeros and ones we are able to represent everything that we see on the computer
